# 🚒 Le macchinine di Lolo

Tira la fionda e guida su 3 corsie con i bottoni ◀ ▶: raccogli stelline, evita gli ostacoli, arriva al traguardo. Pompieri, polizia, ambulanza e camion della spazzatura.

Un giochino semplice per bimbi piccoli, in italiano. Un solo file HTML (Canvas + JavaScript + Web Audio): si apre nel browser su tablet, telefono o PC, senza installare niente. Bottone 🐢/🐇 per la velocità.

**Gioca:** https://antoniobonifacio84.github.io/Lolo-macchinine/

Tutti i disegni e i suoni sono generati nel codice. Nessun dato raccolto.
